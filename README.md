# CMLA — Computational Methods of Linear Algebra

Учебный репозиторий по численным методам решения дифференциальных уравнений в частных производных (ЧМУЧП).

## Структура проекта

```text
CMLA/
├── 3 semester/          # 3-й семестр: одномерное уравнение теплопроводности
│   ├── main.py          # Неявная схема (метод прогонки)
│   └── crank_nicolson.py # Схема Кранка–Николсон
├── 4 semester/          # 4-й семестр: двумерные эллиптические уравнения
│   └── 1(2) task/
│       └── main.py      # Метод Зейделя для уравнения Пуассона
├── requirements.txt
└── README.md
```

## Требования

- Python 3.8+
- NumPy
- SciPy
- Matplotlib

## Установка

```bash
# Создание виртуального окружения (рекомендуется)
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или: venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt
```

## Запуск

### 3-й семестр: уравнение теплопроводности

```bash
cd "3 semester"
python main.py          # Неявная разностная схема
python crank_nicolson.py # Схема Кранка–Николсон
```

### 4-й семестр: уравнение Пуассона

```bash
cd "4 semester/1(2) task"
python main.py
```

## Описание задач

### 3 семестр

- **main.py** — решение одномерного уравнения теплопроводности \( u_t = a u_{xx} + f(x,t) \) неявной разностной схемой с методом прогонки.
- **crank_nicolson.py** — схема Кранка–Николсон с аппроксимацией \( O(\tau + h^2) \).

### 4 семестр

- **main.py** — решение двумерного эллиптического уравнения \( a u_{xx} + b u_{yy} = f(x,y) \) методом Зейделя (итерационное решение СЛАУ с пятидиагональной матрицей).
